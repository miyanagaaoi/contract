## 4. 顺序与关键路径

```
T-01 → T-02 → T-03 → T-04 → T-05 → T-06 → T-07 → T-08 → T-09 → T-10
                                  ↘ T-11 → T-12/T-13 → T-14 → T-15 → T-16 → T-17 → T-18 → T-19
```

- **关键路径**：T-01 → T-03 → T-04（核销与记账是全部功能的地基，不能并行跳过）；

## 6. 验收方式与命令

```bash
# 1) 后端全量回归（隔离临时库）
app/.venv/Scripts/python.exe -m pytest app/tests -q

# 2) 前端构建
cd web && npm run build

# 3) E2E（独立端口 + 临时库；不要碰正在运行的 8000/5173 与真实库）
#    具体步骤见 docs/27 §11 的实操记录（临时 Playwright/Vite 配置 + .dsh/verify 临时库）
npx playwright test 20-finance.spec.ts

# 4) 财务专项冒烟（真实库，运维用；默认 dry-run）
app/.venv/Scripts/python.exe app/tests/smoke_v25_finance.py --dry-run
```

**完成定义（DoD）**：`docs/29` §5 的 AC-V2.5-01~20 逐条有证据（自动化或被记录的人工确认）+ 无遗留阻断问题 +
每个任务一次 Git 提交 + `docs/32-v2.5-acceptance.md` 签字。
