## 2. 角色与场景

角色体系**不变**（沿用 `11` §3，8 类内置角色）。本版涉及的角色与新增能力：

| 角色 | V2.1 变化 |
|---|---|
| 采购员 | 经办人默认自己；可从合同一键提取明细；可现场新增物料 |
| 采购主管 | 下推进度可见、单据自动完成；可自审（若同时持有 admin） |
| 仓管员 | 新增**调拨单**操作；库存明细可看货品总额度 |
| 物料维护员 | 商品类型树状选择、商品类型/计量单位现场快建 |
| admin / superadmin | **可审核自己提交的申请单**（本版唯一权限口径变化） |

**典型端到端场景（V2.1 主线演示）**：

```
物料维护员：树状选中商品类型 → 建物料
     ↓
采购员：新建采购申请单 → 经办人默认自己 → 选关联合同 → 一键提取合同明细（行项自动带物料）
     → 需要新物料时点 + 快建 → 提交
     ↓
采购主管（或 admin 本人）：审核（admin 自审场景）→ 下推生成采购单（合同自动带出）
     ↓
全部行项下推完毕 → 申请单自动"已完成"、下推按钮消失
     ↓
仓管员：入库过账 → 库存明细显示结存与"货品总额度"
     ↓
仓管员：创建调拨单（甲仓 → 乙仓）→ 审核 → 两仓结存同事务变化
```

## 3. 业务规则（BR-V2.1）

| 编号 | 规则 | 类型 |
|---|---|---|
| **BR-V2.1-01** | **经办人**：取值来源为**全部启用账号**；新建单据时默认当前登录账号；账号停用后不再出现在下拉中，但历史单据仍显示其姓名 | 功能 |
| **BR-V2.1-02** | **合同行项绑定物料**：合同行项（`ContractItem`）必须绑定系统物料档案（`product_id`）；新建、编辑、Excel 导入均强制校验；未绑定的行项不允许保存 | 数据 |
| **BR-V2.1-03** | **明细提取**：选择关联合同后，可一键将**该合同全部行项**提取为本单行项，物料、数量、单价作为草稿值带入，用户可修改；单内已有行项时，提取前二次确认覆盖 | 功能 |
| **BR-V2.1-04** | **金额一致性**：行项金额 = 数量 × 单价（保留 2 位）；合计 = Σ 行项金额；前端展示与后端落库使用**同一口径**，不得各算一套 | 数据 |
| **BR-V2.1-05** | **自审例外**：**初始管理员**（`User.is_superadmin=True`，即 `admin` 账号）或持有 `admin`/`superadmin`/**`sysadmin`** 角色的账号可审核自己创建的单据；其他角色仍被拒绝；自审通过时**变更历史与操作日志**均显式记录"自审"（审核人 = 创建人） | 权限 |
| **BR-V2.1-06** | **下推完成判定**：行项剩余可下推量 `remain = qty − ordered_qty`；当**全部行项 remain = 0** 时，单据状态自动置为"已完成"；此时列表不再展示下推按钮 | 流程 |
| **BR-V2.1-07** | **调拨**：单张调拨单表达"调出仓 → 调入仓"；两仓**不得相同**且须属**同一组织**；审核后**同一事务内**完成调出仓减少与调入仓增加；任一步失败整体回滚 | 流程 |
| **BR-V2.1-08** | **调拨与库存**：调拨过账遵循负库存校验（调出仓不足即拒绝）；过账幂等（重复审核不重复过账）；反审核以反向流水红冲；调拨**不产生金额**，**不计入**货品总额度 | 数据 |
| **BR-V2.1-09** | **货品总额度**：= 该 `(物料 × 仓库)` 的**所有批次入库金额合计** = `SUM(qty_change × unit_price)`，仅统计入库方向流水且**排除调拨入库**；退货/红冲等负向入库**冲减**；只读展示，不参与结存与过账 | 口径 |
| **BR-V2.1-10** | **现场快建**：物料、商品类型、计量单位的"快速新增"均在**当前页面弹窗**内完成，保存后自动回填当前字段；**不得跳转离开**未保存的单据页 | 交互 |
| **BR-V2.1-11** | **演示数据**：清理旧演示数据后重建；重建数据中的演示合同**必须包含已绑定物料的合同行项**，以支撑 N2 的演示与验收 | 交付 |

### 3.1 BR-V2.1-09 的口径说明（易争议，重点）

| 问题 | 结论 |
|---|---|
| 统计维度 | 按**明细行**（物料 × 仓库）聚合，**不跨仓库合并** |
| 统计范围 | 入库方向流水（`qty_change > 0`）的 `qty_change × unit_price` 累加 |
| 负向处理 | 退货入库、反审核红冲等负向记录**冲减**（即净额语义） |
| 调拨入库 | **排除**（否则同一批货在仓库间搬运会反复放大额度） |
| 缺失单价 | 历史流水 `unit_price` 为空时按 0 计入，并在界面标注"含未计价批次" |
| 性质 | **统计口径**，不是会计成本，不参与结存、不参与过账、不做计价方法 |

## 4. 详细需求

### 4.1 采购申请单增强（N1~N9）

| 项 | 要求 |
|---|---|
| 经办人 | 由当前"手填数字"改为**账号下拉**（可搜索），默认当前登录账号；展示"姓名（账号）" |
| 关联合同 | 保留现有选择器；**新增"查看合同详情"按钮**，点击后从右侧抽屉拉出该合同只读详情（基本信息 + 行项 + 关联单据摘要） |
| 行项提取 | 关联合同后提供"提取合同明细"动作，按 BR-V2.1-03 带出 |
| 合计金额 | 修复 `[object Object]` 显示缺陷；合计行金额与实际行项金额一致（BR-V2.1-04） |
| 物料快建 | 物料选择框最右侧新增小按钮，点击弹窗新增物料档案，保存后自动回填该行（BR-V2.1-10） |
| 审核例外 | admin/superadmin 可自审（BR-V2.1-05） |
| 下推 | 全部行项下推完毕 → 自动"已完成" + 隐藏下推按钮（BR-V2.1-06） |

### 4.2 采购订单（N10）

- 由采购申请单下推生成采购单时，若**申请单已关联合同**，采购单表头**默认选中同一合同**（编号 + 名称快照一并带入）；
- 采购单仍允许人工改选或清空该合同（不锁死）；
- 该"默认带出"仅发生在**下推**路径；手工新建采购单不受影响。

### 4.3 库存明细（N11~N12）

| 项 | 要求 |
|---|---|
| 货品总额度 | 每行（物料 × 仓库）新增列，按 BR-V2.1-09 计算；只读、可导出 |
| 数量筛选 | 新增「数量」筛选项，形式为**区间**（min ~ max），按结存数量过滤 |
| 物料类型筛选 | 新增「物料类型」筛选项，按**商品类型树**选择；选中父类型时包含其全部叶子类型下的物料 |
| 兼容性 | 既有筛选（仓库、物料、关键字、安全库存高亮）保持不变 |

### 4.4 库存调拨（N13，新单据域）

- **单据形态**：单张调拨单，表头含调出仓、调入仓、经办人、单据日期、备注；行项含物料、数量；
- **编号**：纳入统一编号服务，规则与既有单据一致（新增单据类型码）；
- **权限**：新增 `stock.transfer.*` 权限点（查看 / 新增 / 编辑 / 提交 / 审核 / 作废 / 导出），并配置到相关角色；左侧"库存管理"菜单新增"调拨单"；
- **状态机**：与既有单据一致（草稿 → 待审核 → 已审核 → 已完成 / 已作废），审核触发过账，反审核红冲；
- **流水**：过账产生两条流水——调出仓记「调拨出库」，调入仓记「调拨入库」，两者凭证号相同（同一调拨单号）便于追溯；
- **约束**：两仓不可相同；同组织；调出仓结存不足拒绝；重复审核幂等；有下游（无）——调拨无下游单据，反审核仅受红冲约束。

### 4.5 物料档案（N14~N15）

| 项 | 要求 |
|---|---|
| 商品类型 | 由平铺选择改为**树状展开选择**；选中的必须是**叶子类型**（沿用 AC-V2-09 的既有约束），父类型不可挂载物料 |
| 商品类型快建 | 字段右侧小按钮 → 弹窗新增商品类型 → 回填 |
| 计量单位快建 | 字段右侧小按钮 → 弹窗新增计量单位（含小数位） → 回填 |

### 4.6 演示数据重建（N16）

| 项 | 要求 |
|---|---|
| 方式 | 移走旧库（`app/data/ctms.db`）后重建：`python -m app.init_db --demo` + `python app/tools/seed_demo_v2.py` |
| 演示合同 | **必须为演示合同创建合同行项，且每行绑定系统物料档案**（当前演示合同无任何行项） |
| V2.1 补充数据 | 补充可支撑 AC-V2.1-02（提取明细）、AC-V2.1-10（合同带出）、AC-V2.1-11（货品总额度）的演示数据 |

## 5. 验收场景（AC-V2.1-01 ~ AC-V2.1-21）

> 全部为 **P0**。写法与 `11` §16 一致：Given-When-Then，可执行、可断言。

### 采购申请单

**AC-V2.1-01 经办人默认当前账号（P0）**
- Given 采购员 A 已登录
- When 打开采购申请单新增页
- Then 经办人字段默认为 A（显示"姓名（账号）"），且为**可选择的下拉**而非数字输入框；下拉内为全部启用账号；改选其他账号后保存，详情页显示改选后的账号

**AC-V2.1-02 行项默认提取合同明细（P0）**
- Given 采购合同 C 含 3 条行项，且每行已绑定物料；采购员新建采购申请单并关联 C
- When 点击"提取合同明细"
- Then 申请单行项区新增 3 行，物料、数量、单价取自合同行项；用户可修改数量与单价；若单内已有行项，则提取前弹出二次确认

**AC-V2.1-03 行项汇总金额显示正确（P0）**
- Given 申请单含 2 行：数量 10 × 单价 5、数量 2 × 单价 3.5
- When 查看行项表格合计行
- Then 合计显示为 `57.00`（**不是** `[object Object]`、不是错位到其他列）；该数值与后端保存的 `amount` 合计一致

**AC-V2.1-04 合同行项绑定物料档案（P0）**
- Given 采购员编辑采购合同 C 的行项
- When 未选择物料即保存
- Then 保存被拒绝并提示必须绑定物料；选择物料后保存成功，物料信息（编码/名称/规格/单位）在合同行项中正确显示

**AC-V2.1-05 关联合同后抽屉查看合同详情（P0）**
- Given 申请单已关联合同 C
- When 点击关联合同右侧的"查看合同详情"按钮
- Then 从右侧拉出抽屉展示 C 的只读详情（基本信息 + 行项 + 关联单据摘要）；抽屉可关闭，关闭后申请单已录入数据不丢失

**AC-V2.1-06 管理员可审核自己提交的申请单（P0，⚠️ 修订 AC-V2-15）**
- Given 管理员账号 A（`is_superadmin=True` 的内置 `admin`，**或持有 `sysadmin` 角色的账号**）自己创建并提交了一张采购申请单
- When A 执行审核通过
- Then 审核成功，状态变为"已审核"，**变更历史与操作日志**记录审核人为 A 并标注"自审"；
- And 同时验证：**非管理员**的采购主管 B（`purchase_manager` 角色）提交的单据，由 B 自己审核时仍被拒绝并提示"不能审核自己创建的单据"（原 AC-V2-15 规则对非管理员继续有效）

**AC-V2.1-07 无剩余可下推量时隐藏下推按钮（P0）**
- Given 采购申请单某行申请 100，已全部下推（`ordered_qty = 100`）
- When 打开列表或详情
- Then 该单据**不显示**"下推"按钮；仍有剩余量的其他单据正常显示下推按钮

**AC-V2.1-08 下推完毕自动置为已完成（P0）**
- Given 采购申请单含 2 行，均已下推完毕（全部行项 remain = 0）
- When 完成最后一次下推
- Then 该申请单状态自动变为"已完成"，变更历史记录状态变更；后续不可再下推；反审核后若重新出现剩余量，状态回退并恢复可下推

**AC-V2.1-09 物料快速新增并回填（P0）**
- Given 采购申请单行项需要录入一个尚不存在的物料
- When 点击物料选择框最右侧的小按钮，在弹窗中新增物料并保存
- Then 弹窗关闭，该行物料自动回填为新建物料；**当前单据已录入的其他数据不丢失**（未发生页面跳转）

**AC-V2.1-10 采购订单默认带出关联合同（P0）**
- Given 采购申请单 P 已关联合同 C 且状态为"已审核"
- When 对 P 执行下推生成采购单
- Then 生成的采购单表头默认选中合同 C（编号与名称正确）；仍可人工改选或清空

### 库存明细与调拨

**AC-V2.1-11 货品总额度（P0）**
- Given 甲仓库物料 M 有两次入库：10 × 单价 5、5 × 单价 6，且无退货与调拨
- When 查看库存明细中 M@甲仓库 行
- Then 「货品总额度」显示 `80.00`（= 10×5 + 5×6）；发生退货入库或红冲后该值相应减少；调拨入库**不增加**该值

**AC-V2.1-12 库存明细筛选（数量 / 物料类型）（P0）**
- Given 库存明细含多种物料与数量（含 0 与较大值）
- When 按「数量」区间（如 5 ~ 50）筛选
- Then 仅显示结存数量在该区间内的明细；按「物料类型」选择父类型筛选时，包含其全部叶子类型下的物料

**AC-V2.1-13 调拨单创建（P0）**
- Given 仓管员拥有调拨单新增权限
- When 新建调拨单，选择调出仓、调入仓并录入行项（物料 + 数量）后保存
- Then 单据保存为草稿并自动生成唯一编号；列表可见该单据

**AC-V2.1-14 调拨单校验（P0）**
- Given 调拨单处于草稿且调出仓 = 调入仓
- When 保存或提交
- Then 被拒绝并提示两个仓库不能相同；改选不同仓库后可正常提交，状态变为"待审核"

**AC-V2.1-15 审核同事务过账（P0）**
- Given 调出仓 A 有物料 M 结存 10；调拨单（M，6）从 A 调往 B，状态为"待审核"
- When 审核通过
- Then A 仓 M 结存变为 4，B 仓 M 结存增加 6；产生**两条**流水（A 仓「调拨出库」−6、B 仓「调拨入库」+6），凭证号均为该调拨单号；
- And 若其中一步失败（如 B 仓写入异常），A 仓**不得**被扣减（整体回滚）

**AC-V2.1-16 调出仓不足拦截（P0）**
- Given 调出仓 A 的物料 M 结存 5，调拨单申请调出 8
- When 审核通过
- Then 审核被拒绝并提示库存不足；A、B 两仓结存与单据状态**均不变**，不产生任何流水

**AC-V2.1-17 调拨过账幂等（P0）**
- Given 调拨单已审核并完成过账
- When 重复触发审核（并发或重复点击）
- Then 不重复过账；A、B 两仓结存与流水记录数均不发生变化

**AC-V2.1-18 调拨反审核红冲（P0）**
- Given 调拨单已审核过账（A 仓 −6、B 仓 +6）
- When 执行反审核并填写原因
- Then 追加两条反向流水（A 仓 +6、B 仓 −6），两仓结存恢复至调拨前；原流水保留可查；单据状态回到可编辑状态

### 物料档案与数据

**AC-V2.1-19 商品类型树状选择（P0）**
- Given 商品类型为多层树，存在父类型与叶子类型
- When 在物料档案中展开商品类型选择
- Then 以树状层级展开；选择**父类型**保存时被拒绝（非叶子不可挂载物料）；选择叶子类型可正常保存

**AC-V2.1-20 商品类型 / 计量单位快速新增（P0）**
- Given 物料档案新增页已填写部分字段
- When 分别点击「商品类型」与「计量单位」右侧的小按钮，在弹窗中新增并保存
- Then 弹窗关闭且对应字段自动回填为新建的项；已填写的其他字段不丢失，当前页未发生跳转

**AC-V2.1-21 演示数据重建可用（P0）**
- Given 已按 N16 完成库重建
- When 打开任一演示合同详情，并以其为关联合同新建采购申请单
- Then 演示合同含行项且每行已绑定物料；"提取合同明细"可成功带出带物料的申请单行项
