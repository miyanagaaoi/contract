# 33. 付款申请单打印模板（对齐纸质模板）

> 参考：`docs/.参考文档/合同请示审批单模版.xlsx` 的「付款单 (新) (3)」工作表。
> 实现：`print_template_service.default_config("payment")` + `print_service` 表头字段渲染。

## 1. 参考版式拆解（付款申请单）

```
                        付 款 申 请 单                     日期     计划内 □ 计划外 □
收款信息 │ 收款单位名称 │ ……        │ 开户银行 │ ……  │ 账号 │ ……
付款信息 │ 付款单位名称 │ ……        │ 开户行   │ ……
         │ 一级分类     │ 经营□经济□…│ 付款归属期│ ( )月 本年度□ 以前年度□
         │ 二级分类     │ 具体费用    │ 回单 √   │ 银行付款用途 │ 预付款
         │ 结 算 方 式  │ 银行√现金□  │ 付款事由 │ ……
         │ 金    额     │ 小写        │ 金额（大写）人民币 │ ……
备注     │ ……
签字栏   │ 经理 │ 部门负责人 │ 制单人 │ 财务 │ 财务负责人 │ 领款人
```

## 2. 字段映射（本次补齐）

| 纸质字段 | 系统落点 | 说明 |
|---|---|---|
| 收款单位名称 | `supplier_name`（已有） | 供应商档案快照 |
| 收款方开户银行 | `payee_bank`（**新增**） | 付款单专属 |
| 收款方账号 | `payee_account`（**新增**） | |
| 付款单位名称 | `subject_name`（已有，签约公司） | 我方付款主体 |
| 我方开户行 | `payer_bank`（**新增**） | 与 `pay_account`（账户描述）分开 |
| 一级分类 | `category_l1`（**新增**） | 经营/经济/行政/人力/投资/往来 |
| 二级分类 | `category_l2`（**新增**） | 具体费用 |
| 付款归属期 | `belong_period`（**新增**） | 如 `2026-09` / `以前年度` |
| 银行付款用途 | `bank_purpose`（**新增**） | 预付款/代付款 |
| 付款事由 | `pay_reason`（**新增**） | 与「备注」分开，纸质模板是两个栏位 |
| 金额（小写） | `total_amount`（已有） | |
| 金额（大写） | **自动换算**（`print_service.amount_cn`） | 不落库，避免与大写不一致 |
| 计划内/计划外 | `plan_type`（**新增**） | |
| 结算方式 | `settle_type`（已有） | |
| 签字栏 | 打印模板 `signature_labels` | 默认「经理/部门负责人/制单人/财务/财务负责人/领款人」 |
| 标题 | 打印模板 `title` | 默认「付款申请单」（系统内单据名仍是"付款单"） |

## 3. 落地内容

1. **数据**：`payment_orders` 新增 9 列（`db_migrate._ADD_COLUMNS` 同步，SQLite/PG 均可增量加列）；
2. **接口**：`POST/PUT /api/finance/payments` 接受并按长度落库这些字段（仅付款单，收款单不需要）；
3. **打印**：`HEAD_FIELD_CATALOG` 增加 12 个款项字段（其它单据无此属性会自动跳过）；
   `_head_value_html` 增加对应分支 + `amount_cn()` 金额大写；
   `default_config("payment")` 使用《付款申请单》标题与签字栏；
4. **表单**：付款单表单新增这些输入项（一级分类用下拉、计划内/外用下拉），编辑时回显；
5. **测试**：`TestPaymentPrintTemplate` 3 项（默认版式与签字栏、金额大写 6 组取值、
   新字段保存与打印 HTML 断言）。

## 4. 使用与调整

- 管理员可在「系统管理 → 打印模板 → 付款单」里勾选/排序表头字段、改标题与签字栏
  （旧模板不会自动出现新字段，按既有约定需重新勾选）；
- 金额大写仅供打印展示；若与票面不一致，请改小写金额（大写是算出来的，不会各自漂移）。

## 5. 版式尺寸（严格对齐参考文件）

几何量直接取自参考 xlsx 的「付款单 (新)」工作表，代码中以常量固化（`print_service._PAY_*`）：

| 项 | 参考值 | 实现 |
|---|---|---|
| 纸张 | A4 **横向**，fitToPage 缩放 90 | `@page { size: A4 landscape }`（内容按列宽百分比自适应） |
| 页边距 | 上 0.75″ 右 0.7″ 下 0.75″ 左 1.378″ | `margin: 19mm 17.8mm 19mm 35mm`（同值换算） |
| 列宽 A~G | 6.375 / 5.125 / 7.375 / 24 / 9.875 / 12.375 / 27.75（Excel 字符宽） | `<colgroup>` 百分比，比例完全一致 |
| 行高 | 标题 33、日期 21、明细 24.95×7、备注 35.1、签字 27×2（磅） | 逐行 `height:Npt` |
| 字体 | 标题 16pt 宋体加粗、日期 12pt、正文 11pt、签字 10pt | 同值（SimSun/宋体） |
| 边框 | 信息区 1px 实线，标题/签字行无边框 | 同 |
| 金额小写 | `￥#,##0.00` | `￥` + 千分位两位小数 |
| 金额大写 | `[DBNum2]` 人民币大写 | `amount_cn()`（财务大写，不落库） |
| 勾选样式 | `经营√经济□…`、`银行√ 现金□`、`计划内√` | `_pay_checkbox()` / `_pay_settle()` |

结构为**固定 12 行 × 7 列**：标题行、日期/计划行、收款信息（标签跨 2 行）、付款信息（标签跨 5 行）、
备注行、两行签字栏（经理|部门负责人|制单人 / 财务|财务负责人|领款人）。
**行列与尺寸不随打印模板配置漂移**；可配置项仅「标题」与「签字栏名称」（`default_config("payment")`）。

测试：`TestPaymentPaperLayout` 3 项 —— 几何量（纸张/页边距/列宽百分比/行高/字体）、
版式行序（19 个标签的先后顺序）、取值与勾选串（大写、￥金额、经营√、银行√、付款单不出现行项表）。
