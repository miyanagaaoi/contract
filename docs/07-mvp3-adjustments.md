## 1. 自动编号（新增合同）

- **格式**：`类型码 + 主体码 + 年份(4) + 月份(2) + 6位序号`，紧凑式，例 `PURZC202609000001`；
- **序号规则（已确认：年度递增）**：按「类型码+主体码+年份」递增，次年重置从 000001；月份码取签订日期所在月（未填签期按当天）；已停用合同占号不复用；
- 交互：新增合同时编号**自动生成预览**（选择类型/我方公司/签订日期即刷新，`GET /api/contracts/next-no` 不占号），保存时服务端生成并保证唯一（并发撞号返回 409 提示重生成）；
- 手填编号仅保留给历史/导入等既有通道（唯一约束不变）。

## 2. 合同类型字典（系统可配）

| 代码 | 含义 |
|---|---|
| SAL | 销售/收入（面向客户收款） |
| PUR | 采购/支出（面向供应商付款） |
| COO | 合作/战略协议（不涉及直接金钱往来的框架协议） |
| LAB | 劳动/人事（员工劳动合同） |
| FIN | 金融/投融资（贷款、股权等） |
| NDA | 保密协议（单签或互签保密文件） |
| OTH | 其他(历史)，enabled=false，**不参与自动编号** |

- 存量"采购/销售/其他"保存时自动映射到 采购/支出、销售/收入、其他(OTH)；筛选下拉自动补齐历史遗留值；
- 存储于 KV `contract_types`，`/api/settings/contract-types` 读写；页面内可改名称/说明/启用（OTH 禁启用）。

## 3. 我方主体码

- 新增字段 `subject_code`（我方公司）：默认 `ZC 智澈公司`、`YX 云羲公司`，可增删/改名（KV `subjects` + `/api/settings/subjects`）；
- 编号主体码取该字段；无账号下为全局设置。

## 4. 类型同步标签（自动）

- 保存合同时自动附加【类型名】标签（如选"采购/支出"自动带【采购/支出】），与框架标签同机制（关联表 `auto` 列区分"自动附加"）；
- 类型变更时：旧类型自动标签移除、新类型名标签自动加入；手动加的标签不受影响。
