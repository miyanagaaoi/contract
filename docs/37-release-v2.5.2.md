# V2.5.2 发行说明（增量）

> 标签：`v2.5.2`　产物：`ctms-image-2.5.2.tar`　镜像：`ctms:2.5.2`
> 基线：`v2.5.1`。本版为**五轮业务改进批次**，无破坏性变更。

## 1. 本版内容

**打印与签字**
- 签字栏无边框（通用 + 付款申请单固定网格）
- 库存单据（入库/出库/调拨/盘点）默认签字栏两行：库管员、采购人、财务 / 部门负责人、部门负责人
- 打印前可选人：入库/出库单点「打印」弹出选人对话框，选中系统账号预填姓名+手写留白；
  部门负责人自动带出组织架构指定的负责人
- **电子签名**：账号预存手写签名（Canvas 在线手绘或上传图片），打印时嵌入签字位
  （有签名图印图片、无签名退回姓名+留白）
- 打印模板 5 个组成部分（标题/表头/行项/签字栏/页脚）各有显示开关，默认全开
- 签字栏每行 3 个，超过自动换行

**单据功能**
- 采购单/销售订单：入库/出库完成后「下推」按钮自动消失（行级剩余量判断）
- 出库单：金额自动按先入先出提取入库金额（加权平均，选物料自动带价）；保存/提交时
  负库存前置校验（过账层拦截保留）
- 出库单行项取消仓库列，数量后新增「当前库存」列（按表头出库仓库实时查）
- 销售申请单新增「提取合同明细」（与采购申请单一致）
- 合同行项「数量」列移到「单位」前

**主数据与合同**
- 物料编码留空自动生成（按商品类型码+序号），编辑态只读
- 物料「品牌」改为选择系统供应商、显示简称（落库为文本快照）
- 合同「已付金额」按财务单据取数：采购类取付款单、销售类取收款单（增量回写，
  人工补录值不被覆盖；Contract 新增 received_amount 列）
- 组织架构可指定部门负责人（leader_user_id，打印时自动带出）
- 供应商档案下拉带出开户行/账号，付款单选择后自动填充收款方银行信息
- 我方公司字典扩展开户行/账号/税号，付款单选择签约公司自动填充我方开户行
- 付款申请单打印严格对齐参考模板（A4 横向、固定 12 行 × 7 列、金额大写）
- 付款申请单打印时签约公司显示全称（快照缺失时按主体码反查）

**库存**
- 库存明细「导出结存」左侧新增「导入期初数据」按钮（仅超级管理员）：
  目标值导入、幂等（重复导入全跳过）、错误行跳过有效行提交

**界面**
- 项目 logo 接入（登录页/侧栏/浏览器标签页图标）
- 单据列表「来源单号」「关联合同」可点击 → 抽屉查看上游单据/合同详情
- 下推对话框提示"已下推但未生效"的下游单据

## 2. 数据库变更（启动时幂等自动执行）

- `contracts.received_amount NUMERIC(14,2) NOT NULL DEFAULT 0`（V2.5.1 已有，V2.5.0 用户首次升级会加）
- 无新表、无破坏性变更；签名文件存 uploads/signatures/（无库表列）
